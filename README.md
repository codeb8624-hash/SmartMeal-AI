# VisionFX AI

VisionFX AI is an AI-powered Android application focused on real-time image processing, smart visual effects, and AI-based image enhancement.

## Features
- Real-time AI image effects
- OpenCV-based image processing
- Python FastAPI backend integration
- Modern Android UI
- Scan history management
- Responsive and optimized performance

## Technologies Used
- Java
- Android Studio
- Python
- FastAPI
- OpenCV
- REST API
- XML UI Design
